建築の基本ステップ（回転・反転）
①カードを選択 → ②「回転 / 反転」で向きを調整 → ③敷地をタップして「確定」で配置します。
・反転（鏡写し）：左右反転した特殊加工は通常建築費 +20%かかります（オフィス設備で +10% → 無料化可）。
・PC便利操作：盤面タップ時の「確定」ボタン横にも回転・反転が出ます（キーボード R 回転 / F 反転 / Enter 確定 / Esc 解除に対応）。
部屋の合体・LDK表記・自動ドア
・合体と表記：同じ種類の部屋を隣り合わせて置くと壁が消えて1つの広い部屋に合体し、LDKは合計マス数に応じて「K(1) / DK(2〜4) / LDK(5+)」へ自動変化します（※和室だけは合体せず襖で繋がる独立部屋扱い／UBも通常浴室とは別扱い）。
・通路とドア：廊下同士・玄関↔廊下は赤い壁がない限り全辺オープンに繋がります。異なる部屋同士が接すると、1ペアにつき1箇所だけ自動でドアが開きます。
赤い壁（耐力壁）と有料撤去
・赤い斜線の辺は確定の壁で、ドアが開かず合体もしません（外周にあれば窓も塞がります。なお、合体で内部に取り込まれた赤い壁は無効化され撤去対象外です）。
・カード未選択の状態（選択中カードをもう一度押すと解除）で赤い壁をタップすると、費用（5万 → 10万 → 20万 → 40万［上限］）を払って壁撤去できます。
動線（到達不能のダブルペナルティ）
玄関からドア・廊下を通って辿り着けない部屋（「到達不能」）が残ると、1箇所につき基本家賃が大きく低下（-30%／下限10%）するうえ、NGコンボ1つ分の悪評（満足度-20%・劣化速度+0.5%/月）も受けます。
窓ができる条件（・南向きLDK）
・窓が付く部屋：水色の窓が付くのは「LDK（K/DK/LDK）」と「居室（洋室・和室）」だけです（玄関・廊下・トイレ・風呂・洗面・収納等は外に面しても壁のまま）。
・窓が開く条件：部屋の外側が空きマス・庭・敷地外（✕マス／盤面端）に面しており、かつ赤い壁（耐力壁）が無い辺に自動で付きます。
・南向きLDKの条件：LDKの下側（南辺）に窓があり、その真下（盤面端まで）を遮る別の部屋が1つもない状態。
敷地のルール（白マス・✕マス・隣接）
・白いマス：通常の建築可能エリア。
・網掛け✕マス（敷地外・障害物）：置けない壁ではなく、高額な造成費＋毎月の重い維持費（通常の5倍：0.20万/マス）を払えば強引に拡張できる非常用スペースです（プレビューが黄色になり「確定 (+造成XX万)」と表示）。
・隣接必須（飛び地NG）：どのピースも、玄関か既に置いた部屋・廊下に1辺でも接していないと配置できません。
「庭」の自動判定ルール
建物を囲う最小の長方形の内側にできた空きマス（✕マスは除外）が、自動的に緑枠の「庭」として認識されます。
※ L字やコの字型に囲って庭を作れる反面、庭にも毎月 0.06万/マス の維持費がかかります。
デッキの3層構造（20〜24枚）と技術開発
山札はホーム「オフィス ＞ デッキ」または案件画面「デッキ編成」から組み替えできます。
・固定枠（11枚）：生活インフラの基礎ピース（事故防止のため変更不可）。
・同カテゴリ入替枠（9枠）：開発した同カテゴリの上位ピースへ差し替え可能。
・自由追加枠（最大 +4枚）：解放済みの全カテゴリから自由に追加（空枠も可）。
・技術開発（10種・80〜300万）：和室・大型LDK・WIC・長3/T/Z廊下などを永久解放。
※建築途中でオフィスから変えても今の山札には反映されず、次の「設計開始」（またはやり直し）から反映されます（案件確認画面からは即反映）。
更新（リロール）の無料枠と手札補充ルール
・手札補充：手札（標準3枚、設備「設計テーブル拡張」で4→5枚）は1枚置くごとではなく、手札をすべて使い切った時に一括補充されます。
・更新コスト：「KEEPせずに捨てた累計枚数」で決まります：初期無料枠5枚まで 0万、超過 +1〜5枚目は +2.0万/枚、+6〜10枚目は +4.0万/枚、以降 +8.0万/枚（※空枠の補充は 0万）。
・軽減と引直：設備「無料破棄枠」やスタッフスキル「中古調達」（無料枠増加＆超過費用割引）で軽減できます。また、スキル「戦術手札」の「引直」ボタンは手札を山札に戻して混ぜ直すため、無料破棄枠も山札周回も消費しません（KEEPは解除）。
KEEP（ロック）の維持コスト
カード左上の 🔓keep を押すと次の更新でも手札に残せます。
ロックして1回目の更新を跨ぐ時は 0万（無料）ですが、ロックしたまま2回目以降の更新を跨ぐごとに 1万 → 2万 → 4万 → 8万…（2の累乗）で倍増します。
山札の周回割増・やり直し・諦める
・山札の2周目以降：山札を引き切って捨て札を戻すと、建築費が2周目 +25% / 3周目以降 +50%になります（割増率は引いた時点で固定／左上の「山札」ボタンで残り内訳を確認可能）。
・もう一度設計／諦める：結果画面の「もう一度設計」は着工前の資金に戻して再設計（通常2回、設備「再設計保険」で最大4回）。「諦める」も建築費は戻りますが、1ヶ月が経過（月次収支・給与・返済が発生）し依頼一覧3件が入れ替わります。
・依頼詳細・コンボ確認：画面上の要望バー（「詳細」）タップで達成状況と発生コンボを確認できます。
「原価」と「諸経費」・引き渡し条件
・原価 vs 諸経費：家賃や売却査定額の基準になるのはピースの定価「原価」のみです。反転加工費・山札周回割増・更新費・壁撤去費・造成費などの「諸経費」は物件価値を上げない純粋なコストになります（逆にスタッフの資材割引は物件価値を下げずに支払額だけお得です）。
・引き渡し条件：設計完了時の足切りはなく、目標未達や建築途中でも「設計完了」→物件を引き渡すこと自体は可能です。
売却は「築6ヶ月（半年）」から＆経年減価
建てたばかりの物件には6ヶ月間の売却ロック（🔒売ロック表示）がかかります。
・オーナーチェンジ売却（入居中）：査定売価の満額で売却可能。
・空室売却（空室中）：査定売価の20%引きになります。
・査定と減価：満足度80%未満だと基礎評価が減額され（コンボ加算も80〜100%で段階反映、上限+50%）、さらに築1ヶ月ごとに -2%ずつ減価（下限30%）します。
コンボ（全30種）・記録帳と「珍間取り」の特性
・コンボ評価：王道（11種）・珍間取り（13種）は家賃加算＋満足度 +5%、NG（6種：玄関直風呂・食欲減退・スケルトンバス・プライバシーゼロ・マトリョーシカ・トイレビュッフェ）は家賃減額＋満足度 -20%・劣化速度 +0.5%/月・再入居率 -5%。
・珍間取りの隠れ特性：「ロングコリドー」以外の珍間取り12種には「飽きられやすい（劣化速度 +0.2〜+0.5%/月・空室時の再入居率 -5〜-20%）」というデメリットがあります。
・記録帳：「設計完了（査定時）」に発生していたコンボが図鑑へ自動登録されます。
満足度バリア・2代目以降の市場家賃・維持費
・生活設備と保証：トイレ未設置（満足度-25%）・浴室未設置（-15%）は大減点。入居初月は退去判定なし。初代で満足度100%超の分は退去率0%保証期間（120%超は2%=1ヶ月）になり、2代目以降（一般市場）は最初の3ヶ月間が退去率0%保証＆特注プレミアムが外れて市場家賃（年-8%、下限60%）になります。
・毎月の維持費：「延床 0.04万/マス ＋ 庭 0.06万/マス ＋ 造成区画 0.20万/マス」（最低0.2万）＋築1ヶ月ごとに +4%ずつ増加します（空室中は家賃0で維持費のみ発生）。
オフィス移転割引と営業・ブランド・設備投資
・ゲーム目標：オフィスを移転し、Rank 5「本社自社ビル」到達を目指します（到達後もエンドレス継続可）。「施工実績・設計品質（累計良コンボ−悪コンボ）・累計家賃」の達成で移転費が大幅割引され、管理棟数・デスク数・各設備の上限が解放されます。
・営業力（Lv1〜5）：依頼の予算・目標家賃が +15%/Lv（最大1.6倍） 上昇＋空室再入居率 +2%/Lv。
・ブランド（Lv1〜5）：富裕層・豪邸案件の出現率UP＋銀行融資枠 +200万/Lv＋空室再入居率 +3%/Lv。
スタッフ採用の維持費・スキル重複・昇給交渉
・同スキルは最大Lvのみ適用：複数人が同じスキルを持っていても合算されず、最高Lvのみ有効です（満席時の入替雇用・解雇の退職金は0円）。
・求人広告の維持費に注意：広告掲載の翌月から候補が3名並びますが、募集中（アクティブ）の間は毎月 15.0万 の広告維持費がかかり続けます（即時スカウト後も枠が残っていれば継続）。見送る時は必ず「掲載停止」を押してください。

銀行・街金の返済ルールと2つの倒産条件
・最低着工資金：所持金 15.0万未満 では新規設計を開始できません。
・担保と毎月自動返済：銀行融資枠は「基礎100万＋ブランド加算＋物件担保（入居中：売価×2.0 / 空室：売価×0.5）」。毎月、銀行は「残債5%（最低10万）＋月利1.5%（最低0.2万、金利交渉で軽減）」、街金（上限50万）は「残債5%（最低1万）＋月利10%」が自動返済されます。
・街金の注意点：手動借入時は即時手数料 +10% が残債に加算され、建築中に借りた街金残債は「もう一度設計」「諦める」で資金を戻しても消えません。街金残債がある間は銀行の新規借入が停止します。
